# tasks-breakdown
A coursework task tracker built to manage and organise weekly deliverables for a group web development project (SDG-themed website). Each student section is password-protected to keep tasks separated and accountable.
Features

Weekly task breakdown per student
Password-protected sections for each group member
Progress tracking
Built as a single-page HTML file — no setup required

Built with

HTML, CSS, JavaScript (single file)

Live site
https://dthwwydfli.github.io/tasks-breakdown/
Context
Built as a personal organisational tool alongside a university group coursework project at the University of Westminster. The project involves building a multi-page website around a UN Sustainable Development Goal.
How it was made
Developed with the assistance of Claude (Anthropic's AI) as a coding collaborator. The structure, password logic, and task organisation were designed and directed by me to fit the specific needs of the group project
